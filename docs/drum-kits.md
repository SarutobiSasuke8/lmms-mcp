# Licence-clean drum kits

- **synth_drums** generates one to sixteen original 48 kHz mono WAVs and a provenance manifest in a new workspace folder. Choose kick, snare, clap, closedHat, openHat, rim, tom, crash, ride, sub808 or hardstyle; set MIDI pitch, length in milliseconds, click, drive and seed per hit. Drum output is capped at −1 dBTP and catalogue records identify the MIT synthesizer.
- **fetch_kit** downloads the seven selected one-shots from [FreePats synthesizer percussion](https://freepats.zenvoid.org/Percussion/electric-percussion.html) into the user cache, without credentials. It accepts only the pinned 2022-07-18 CC0 archive and verifies the SHA-256 of both the archive and every selected WAV. The manifest records author, licence, source, digest and drum role per file. Windows includes the required archive reader as tar.exe; on other platforms install bsdtar in addition to tar. If a cache entry differs, move the cache folder aside and fetch again after checking the source.
- **build_kit** maps workspace WAVs to General MIDI percussion keys and writes an LMMS audition project, a Decent Sampler preset, a channel-10 MIDI audition and a mapping manifest. Copy the selected cache WAVs and their source manifest into a workspace folder before building a kit. Keep the source manifest with the kit; the mapping manifest records SHA-256 so the sources can be matched later. The preset paths are relative to the preset. The LMMS project uses workspace sample paths.
- **layer_drum** combines two to eight workspace WAVs using independent offsets in milliseconds and gains in dB. It resamples to 48 kHz, preserving stereo if any input is stereo. **tune_drum** resamples one WAV between two MIDI pitches (within two octaves), so an octave up halves the duration. Both tools cap true peak at −1 dBTP and refuse to overwrite an existing file.

Stock LMMS kits still use the existing tools and are marked non-publishable. Building a kit from arbitrary WAVs does not clear those files for publication.
